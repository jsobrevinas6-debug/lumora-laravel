# EditGod — Company Profile Website

## Introduction

A Company Profile Website is a multi-page site that introduces a business to the
public — who they are, what they offer, and how to reach them. It typically
includes a Home, About, Services, and Contact page.

Businesses need one because it's often a customer's first impression of the
company online — it builds credibility and gives potential clients a place to
learn about services and get in touch.

The purpose of this project is to build a company profile website for EditGod
using Laravel's MVC architecture, applying routing, controllers, and Blade
templating to create a reusable, well-organized multi-page application.

## Objectives

- Implemented Laravel routes for Home, About, Services, and Contact pages
- Built a CompanyController to handle each page request
- Created a reusable Blade layout with shared navbar and footer components
- Built four fully styled pages using Tailwind CSS
- Applied Git version control with meaningful commit messages throughout development
